# SlateRandom 岩选的窗口与动画渲染

作者：DeepslateQAQ。

普通视图跟随当前焦点，全览按钮开启后保持完整座位表。旧 `cinema` / `cinematic` 配置自动恢复为普通；渲染方式不改变抽选结果、公平统计或随机序列。

## Windows 与 UIAccess

普通权限保留 Electron 默认加速路径。UIAccess 在 Chromium 初始化前禁用 DirectComposition 呈现路径，保留可用的 GPU 光栅化和画布加速。主界面使用不透明窗口，UIAccess 的显隐在 renderer 内完成，避免原生透明度造成不可见窗口。

GPU 能力由实际 Windows 驱动与 Chromium 决定，虚拟机可能回退软件渲染。窗口可见性和动画仍按实际窗口状态处理。

悬浮球默认使用 CSS 透明抗锯齿边缘。显式启动参数 `--slate-renderer=software` 用于驱动故障排查，不是默认设置。提权交接保留该参数。

每 1.5 秒重申置顶并使用不激活窗口的 Z 序操作。主界面打开时悬浮球隐藏，收起后以 `showInactive()` 恢复；悬浮球不可获取焦点。隐藏窗口不会被定时检查重新显示。

## 减少重复工作

- 连坐旋转缓存固定网格几何，布局尺寸变化后才重新测量。
- 相机批量测量布局，重复变换不再次写入。
- 座位结构不变时复用节点，更新抽中、已抽、暂停、名称和无障碍信息；抽选边界显式清理临时高亮。
- 日期／时间按数字或候选资格变化更新；同一秒复用有效取位和公平候选，秒数正常跳动。
- 唯一引擎先确定请求模式，再按需建立时间或连坐候选；指定普通模式不扫描连坐起点。连坐计划只在本轮从公平候选建立座位坐标索引，并在抽选及末尾改选中复用，不跨可变班级状态缓存。
- 远光使用局部径向渐变，保留近光与明亮轮廓，减少大范围、多次高斯模糊。

## 触摸移动

Windows 触摸事件中，`PointerEvent.screenX/Y` 可能是客户区坐标。触摸点使用窗口原点加 `clientX/Y`，鼠标仍使用绝对屏幕坐标。每个手势独立标识并合并帧内更新，旧异步回调不能控制新手势；触摸采用短程指数平滑，抬手提交真实终点。

在分数 DPI 下反复使用 Electron 返回的窗口尺寸，可能逐步扩大球体。移动始终使用设计尺寸 76×76 DIP；正常抬手后吸附到边缘，取消手势或丢失捕获时取消本次操作。

长按 3 秒的进度以球体外侧黑边中的 SVG 环显示，使用非线性描边动画，不覆盖绿色球面、不增加窗口尺寸或大范围滤镜。拖动开始即取消长按计时和进度环。
