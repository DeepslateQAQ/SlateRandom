# SlateRandom 岩选便携数据与备份

Windows 版把数据保存在 `SlateRandom.exe` 同级的 `data/`；开发模式使用项目根目录的 `data/`。移动完整程序目录即可携带名单、设置、抽选进度和累计公平统计，运行设备无需安装 Node.js。目录不可写会明确提示，不会改存 AppData。

## 本机文件

| 文件 | 内容 |
| --- | --- |
| `data/roster.json` | 班级、姓名、学号、座位、启用状态和友尽目标 |
| `data/settings.json` | 抽选规则及视觉、语音提供商配置 |
| `data/desktop-settings.json` | 自启动、权限和悬浮球位置等桌面偏好 |
| `data/statistics.srstat` | 累计公平统计、出场位次、当前抽取进度、历史、撤销与随机状态 |
| `data/.fairness-key` | 公平统计文件的便携校验密钥 |
| `data/browser/` | Electron 浏览器会话及迁移资料 |
| `data/cache/tts/` | 桌面版默认 Edge 朗读的姓名音频缓存，不纳入备份或发布归档 |
| `data/.portable-migration.json` | 旧版复制迁移完成标记，不包含名单或服务密钥 |

名单和设置使用 UTF-8 JSON。新统计文件使用 UTF-8 JSON、deflate 压缩和 AES-256-GCM 完整性校验，跨 Electron／Node.js 版本读取。`SLATEST1` 文件头后的 16 位大端编码版本为 2，数据 schema 仍为 version 1。旧编码版本 1 的 V8 统计兼容读取，下次正常保存时自动升级。配套密钥与统计文件一同携带。

桌面版默认 Edge 朗读固定使用晓晓（`zh-CN-XiaoxiaoNeural`）。音频仅在成功合成后按需缓存，不预先合成整班名单；相同文本、实际音色与合成参数可复用缓存。默认上限 64 MiB，超出时优先清理最久未使用的音频。缓存包含姓名音频，可在「功能 → 朗读设置」中点击「清空姓名语音缓存」清空。Lite 默认使用浏览器语音，不使用此音频缓存。

搬迁时请复制整个 `data/`，包括统计文件和 `.fairness-key`。程序通过事务日志保存关联文件；保存中断后，下次读取会继续完成。文件损坏、密钥缺失或数据不匹配时，程序会保留原文件并提示错误。修改名单和座位请使用「名单」页面，恢复备份请使用「数据」页面。

学号在输入层归一化为 1～12 位正整数字符串，便携存储保留同一身份，不另行转换前导零。维护名单时，已确认匹配的同学保留累计公平统计；若移除同学使历史记录出现缺口，缺口及更早的历史不再可撤销，缺口后的连续记录仍可撤销。新抽取仍可撤回到名单维护后的状态，不会跨越缺口清除保留同学的统计。

## 从旧版本升级

首次启动便携版本会检测旧 `%APPDATA%/SlateRandom`。只有尚未建立便携名单、统计、浏览器目录或迁移标记时才复制旧浏览器资料；已存在的便携数据优先。旧桌面设置仅在目标文件缺失时复制。

复制保留 Local Storage、IndexedDB、网络资料与 Preferences，包含数据库必须的编号 `.log` 文件；排除浏览器缓存、GPU 缓存、锁、实例标记和应用日志。资料先复制到 `data/` 内的独立暂存目录，再整体发布；失败可重试，旧目录原件不删除。程序拒绝互相包含的迁移路径及符号链接／目录联接，避免递归复制或访问目录外的资料。

首次正式加载时，旧名单和统计转换为新文件，旧提供商资料转换到 `settings.json`。旧目录保留作为原始副本，不再作为持续同步源；之后修改旧版本不会覆盖便携版本。

## 数据页面

设置统一分为通用、功能、名单、数据、帮助、关于六页。备份与累计统计集中在“数据”。

| 导出类型 | 格式 | 内容 |
| --- | --- | --- |
| 设置 | JSON | 抽选方式、概率、朗读与提供商配置 |
| 名单 | JSON | 班级、学生、座位与友尽目标，不包含公平统计 |
| 全部 | `.slate` | 名单、设置、累计公平统计、历史、当前进度和随机状态 |

API 密钥默认从导出中移除。确需迁移识别或朗读密钥时，开启“备份中包含 API 密钥”，并妥善保管导出文件。包含密钥的备份不受密码保护，请勿公开分享。备份未包含的密钥仅在提供商及完整规范化接口地址均未改变时沿用；接口的协议、主机、端口、路径或查询变化后需重新填写。显式空密钥会清除原密钥。源码、名单 JSON 与 CSV 记录不包含这些密钥。

全部恢复会替换当前数据，导入前先检查格式、版本、完整性和领域状态。设置单独导入不修改名单或公平统计；名单导入通过姓名匹配保留已有同学的累计记录。旧版班级 JSON 仍可使用“恢复全部”导入。

完整恢复会重新读取班级和识别、朗读设置，完成后显示成功。若遇到问题，请保留备份并重新使用「恢复全部」；期间仍可查看和导出名单、记录。普通保存失败时保留当前编辑内容，并显示「尚未保存」。

Lite 使用 localStorage 保存班级，两份 IndexedDB 分别保存识别和朗读设置。恢复前会读取旧资料；班级写入前失败时，会尝试还原提供商设置。班级写入成功后保留新数据，读取或还原失败时提示重新恢复。

`.slate` 使用 `SLATERANDOM-BK1\n` 格式头、便携密钥、AES-GCM 验证和 gzip 压缩 JSON，桌面版与 Lite 双向兼容。它与本机 `statistics.srstat` 格式不同，迁移时请在「数据」页面导出全部备份。包含 API 密钥的备份请妥善保管，勿公开分享。

## Lite 与更新交付

浏览器版名为 SlateRandom 岩选 Lite，可打开 `SlateRandom-Lite.html`、兼容文件 `点到.html` 或桌面原有 HTML。桌面原 HTML 路径继续保留，便于沿用之前的浏览器记录。

Lite 无法直接向 HTML 所在目录自动写文件。其名单和状态保存在当前浏览器的 `localStorage`，提供商使用独立 IndexedDB；移动 HTML、更换浏览器或设备时，使用全部备份迁移。Lite 隐藏桌面窗口、自启动和提权控件。

发布 ZIP 与源码 ZIP 均不包含个人 `data/`。更新下载目录中的桌面应用时只替换程序文件，保留该目录中现有的 `data/`；源码归档从独立干净目录制作。
